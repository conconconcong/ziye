# 字野 · 让字撒点野

笔画实时生成的矢量手写标题工具：输入标题，字从笔画开始生成，每一笔都可以拉伸、弯折、旋转，再套上材质，导出 PNG 和 SVG。

## 功能

- **笔画级编辑**：「改笔画」模式下拖动笔画节点，直接改变字的骨架——伸长、转向、弯成弧线；「随性一下」一键重新随机手抖纹理和夸张笔画。
- **字形系统**：手写 / 圆润 / 规整 / 书写粗细四种骨架规律，8 种笔触（单线、横细竖粗、扁笔、毛笔、马克笔、签字笔、秀丽笔、宋体笔势），衬线、转折、点形都可调。
- **材质效果**：塑料、橡皮泥、毛线刺绣、云朵、气球（亮面 / 铬银 / 镭射 / 哑光）、毛绒、内描线、划痕 8 种材质，PNG 里保留；导出 SVG 时输出干净矢量字形，方便继续加工。
- **排版变形**：阶梯错位、波浪、弧形、整体旋转倾斜、拉伸；撑满居中、突出重点词一键完成。
- **AI 智能排版**：千问读取当前稿和设计方向，理解意群与焦点，为每套方案制定断行、层级、对齐和留白，并输出带理由的右侧参数调整，包括字距行距、笔画轻重、字形气质、错落变形、材质和背景。可保留当前字形与配色，只调整参数；每稿展示实际调整值和理由，并支持“沿这稿精修”，将渲染后的字号比例、行宽、碰撞与边界摘要送回模型继续改进。本地校验参数范围、字体模式兼容性与实际字形；套用可撤销。未开启 Agent 时可使用本地规则；内网调用需要自行部署中转环境（本仓库不包含相关凭据与配置）。
- **模板库**：18 款精选版式（横版海报、小红书竖版、公众号封面、竖屏故事），18 组配色，快照模板可以保存整份作品并原样还原。
- **导出**：PNG / SVG。

## 使用

网页地址：<https://conconconcong.github.io/ziye/>

直接用浏览器打开 `index.html` 即可，无需构建、无依赖。

中文字体位于 `fonts/` 目录（含毛笔字体 Ma Shan Zheng、演示秋鸿楷）。应用支持导入本地字体（TTF / OTF / WOFF / WOFF2）。
